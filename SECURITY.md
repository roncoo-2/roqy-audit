# Security Policy

## Reporting a vulnerability

Email security@roqy.io with details. We respond within 72 hours.

Please do not open a public issue for a security report.

## Scope

This repository contains audit tooling (read-only check definitions and a
validation harness). If you find a way the tooling itself could cause a write
operation against an audited environment, or a way secrets could leak through
the harness, that is exactly what we want to hear about.

## Safe harbor

We will not pursue legal action against good-faith research that respects the
read-only nature of the tooling and does not touch third-party environments.
